# Encapsulation
1. You always work in an isolated virtual environment activated using .venv/bin/activate.bat.
2. You prepare and adjust a dedicated requirements.txt for needed pip installs.


# General coding rules
You write clean code by applying the following rules:
- names are meaningful and distinctive
- functions do only one thing
- number of function arguments is kept to minimum
- avoid duplicating code
- avoid overcomplicating solutions or complex design patterns
- only write code for requirements currently needed
- avoid deep nesting
- keep code vertically dense
- LEAVE THE CODE CLEANER THAN YOU FOUND IT

# Code structure
You structure your code from top to bottom in the following blocks:
1. module imports
2. constant definitions
3. class definitions
4. function definitions
5. class instantiation
